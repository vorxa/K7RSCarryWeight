# K7 - Race&Sex Carry Weight (плагин SKSE)

Базовый переносимый вес игрока по расе и полу для Skyrim SE (1.5.97) и AE (1.6.x, 1.7.x); Skyrim VR не поддерживается.
English version: [README.md](README.md).

## Состояние

Версия 0.2.1: базовый переносимый вес по расе и полу, учёт штрафа Survival Mode и меню настроек готовы и приняты в
игре на Skyrim AE 1.6.1170. Версия 0.2.1 исправляет показ строки синтаксической ошибки сломанного `config.user.toml` в меню настроек. На Skyrim SE и AE 1.7 плагин в игре не проверялся.

## Что делает

Каждая играбельная раса получает свой базовый переносимый вес для мужчины и для женщины вместо 300 для всех. Значение
заменяет только базу: бонусы выносливости от повышения уровня, предметы, заклинания и другие моды по-прежнему
прибавляются к нему. У нового персонажа без бонусов переносимый вес в точности равен заданному значению.

Плагин кладёт разницу между значением и базой расы в постоянный модификатор переносимого веса и запоминает, сколько
прибавил, в Co-Save SKSE (файл `.skse` рядом с сохранением). Он пересчитывает вес при загрузке сохранения, при смене
расы игрока и при закрытии меню создания персонажа и применяет только разницу, поэтому другие моды, меняющие
переносимый вес, складываются с ним. Вампирские версии рас считаются своей расой. В облике зверя (оборотень, лорд-вампир)
плагин не пересчитывает и сохраняет то, что применил до превращения. Раса, которой нет в настройках (раса из мода),
остаётся нетронутой.

## Survival Mode

Survival Mode отнимает у игрока переносимый вес (150 в файле Creation Club, 100 с Survival Mode Improved - SKSE). С
низкими значениями этого плагина игрок был бы перегружен всё время, поэтому, пока штраф действует, плагин гасит его и
вместо него отнимает от значения `survival_penalty` очков (по умолчанию 0: переносимый вес такой же, как без Survival).
Размер штрафа плагин читает из эффекта штрафа на игроке и проверяет раз в секунду, потому что Survival включается и
выключается без события (после загрузки или в настройках игры). Если Survival Mode не установлен, ничего не проверяется.
Раса, которой нет в настройках, и `enabled = false` оставляют штраф как есть. `bDisableCarryWeightPenalty` в Survival
Mode Improved больше не нужен; работает любое значение.

## Меню настроек

Если установлен SKSE Menu Framework, плагин добавляет раздел в его окно (открывается клавишей фреймворка, по умолчанию
F1): **K7 - Переносимый вес по расе и полу** (в игре на английском: «K7 - Race&Sex Carry Weight») → **Настройки**.
Фреймворк необязателен: без него плагин работает по файлам и пишет об этом одну строку в журнал.

Меню показывает персонажа (раса, пол, база расы, переносимый вес по настройкам, поправка плагина, что ещё меняет
переносимый вес, итог), прочитанные файлы и ошибки в них, и правит настройки: ключи `[general]`, значения каждой расы для
мужчины и женщины, расу персонажа как новую расу из мода, записи рас, облики зверя и эффекты Survival Mode. Значения вне
диапазона не принимаются; запись принимается, только если она есть в игре и это раса (для Survival Mode — эффект).

«Сохранить» записывает `config.user.toml` и сразу применяет изменение, без загрузки сохранения. Записывается только то,
что отличается от `config.toml`; **комментарии и порядок строк в `config.user.toml` не сохраняются**, поэтому прежний
файл копируется в `config.user.toml.bak` перед первой записью за игровую сессию. «Сбросить» в строке расы убирает её
правку из файла. Записи ванильных рас, встроенные облики зверя и эффекты Survival убираются только правкой файла. Если
`config.user.toml` не читается, меню показывает ошибку и не пишет поверх него («Начать с чистого файла» сохраняет его как
`.bak`). Если файл изменился на диске после чтения меню, меню спрашивает, перезаписать его или перечитать.

Тексты меню лежат в `Data/SKSE/Plugins/K7RSCarryWeight/lang/english.toml` и `russian.toml` (берётся язык игры, иначе
английский); перевод — ещё один файл с теми же ключами. Для кириллицы нужен шрифт, который её рисует, например из мода
«SKSE Menu Framework Rus».

## Установка

Нужны: SKSE64 и Address Library for SKSE Plugins для вашей версии игры. Установите мод менеджером модов или скопируйте
`SKSE/Plugins/K7RSCarryWeight.dll` в `Data/SKSE/Plugins/`. ESP и Papyrus не нужны.

При первом запуске плагин пишет `Data/SKSE/Plugins/K7RSCarryWeight/config.toml` (в Mod Organizer 2 он попадает в
`overwrite`) и журнал в `Documents/My Games/Skyrim Special Edition/SKSE/K7RSCarryWeight.log`.

## Настройка

В `config.toml` лежат встроенные значения с комментарием к каждому ключу, и он **перезаписывается при обновлении
плагина**. Свои изменения кладите в `config.user.toml` в той же папке: указывайте только то, что меняете, остальное берётся
из `config.toml`. Изменения вступают в силу после перезапуска игры или загрузки сохранения.

```toml
[general]
enabled   = true     # false: плагин забирает свой вклад обратно (см. «Удаление»)
min_total = 20       # ни у одной расы база не опускается ниже этого значения, от 1 до 300
log_level = "info"   # trace | debug | info | warn | error
survival_penalty = 0 # вместо штрафа Survival Mode, см. «Survival Mode»

[races.nord]
male = 120           # одно поле ванильной расы; female и forms остаются как в config.toml

[races.my_mod_race]  # раса из мода со своими значениями
forms  = ["MyRace.esp|0x000800", "MyRace.esp|0x000801"]   # записи расы: плагин | локальный form id
male   = 110
female = 95

[beast]              # превращения без пересчёта; заменяет список, поэтому оставьте две ванильные записи
forms = ["Skyrim.esm|0x0CDD84", "Dawnguard.esm|0x00283A", "MyMod.esp|0x000900"]
```

Значения рас — целые числа от 1 до 1000. `forms` в `config.user.toml` заменяет список записей расы целиком: чтобы
добавить запись к ванильной расе, перечислите и её две ванильные записи, иначе ванильная раса и её вампирская версия
выпадут из настроек и вклада не получат. Запись расы, названная двумя расами, достаётся той, что названа позже
(`config.user.toml` сильнее `config.toml`). Запись, которая есть и в расе, и в `[beast]`, считается только обликом
зверя, о чём в журнале пишется предупреждение. Неверное значение пропускается и попадает в журнал с файлом, ключом и
строкой; остальной файл применяется. Файл, который не читается, не применяется и не перезаписывается.

Чтобы найти форму расы из мода, откройте мод в xEdit (FormID записи без байта порядка загрузки) или посмотрите журнал при
`log_level = "debug"`: когда у игрока раса, которой нет в настройках, строка пересчёта называет её, например
`race MyRace.esp|0x000800 [not in configuration]`.

## Удаление

Вклад плагина хранится в сохранении, а не в DLL. Если удалить только DLL, вклад останется там навсегда, а при повторной
установке плагин уже не знает о нём и добавит второй раз.

1. Поставьте `enabled = false` в `config.user.toml`.
2. Загрузите свою игру: в журнале будет `contribution … -> 0`, переносимый вес вернётся к ванильной базе.
3. Сохранитесь, выйдите и удалите мод.

Делайте это в обычном облике персонажа, не оборотнем и не лордом-вампиром: в облике зверя плагин сохраняет свой вклад
даже при `enabled = false` и забирает его, только когда персонаж вернётся в обычный облик, так что сохранение,
сделанное в облике зверя, всё ещё несёт его.

Если вы уже удалили плагин без этих шагов и поставили обратно, плагин этого не определит: вклад лежит в сохранении дважды.
Журнал предупреждает, только когда переносимый вес оказывается ниже `min_total`. Лишний вклад можно убрать консолью,
`player.modav carryweight <значение>` (значение — вклад с обратным знаком; его показывает строка журнала
`contribution … -> X`).
