# Журнал изменений

Здесь записаны все заметные изменения K7 - Race&Sex Carry Weight (плагин SKSE). Это русская версия файла
[CHANGELOG.md](CHANGELOG.md), оба файла ведутся вместе и должны совпадать по содержанию.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[семантическому версионированию](https://semver.org/lang/ru/).

## [0.2.2] - 2026-11-18

### Исправлено

- При отключённом из-за повреждённого co-save пересчёте переносимого веса одна и та же ошибка больше не повторяется при каждой проверке Survival Mode.
- Локализованы сообщения о проблемах настроек и ошибках записи в меню с указанием файла и строки; подробности остаются в журнале плагина.
- Меню сравнивает пользовательский файл с версией, загруженной в настройки. Согласованные операции записи выполняются последовательно и используют уникальные временные файлы.

- При повреждённом или неконечном сохранённом вкладе пересчёт переносимого веса останавливается, а это состояние сохраняется. Неконечный результат пересчёта также не применяется.

### Изменено

- Перед заменой существующей конфигурации создаётся уникальная проверенная копия с датой вне папки мода; существующий файл `.bak` сохраняется.

## [0.2.1] - 2026-11-10

### Исправлено

- Меню настроек показывает синтаксическую ошибку `config.user.toml` с номером строки, если файл ломается во время игры. Раньше выводилась только строка «файл не читается», а самой ошибки в меню не было.

## [0.2.0] - 2026-11-07
